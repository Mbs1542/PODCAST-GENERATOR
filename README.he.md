## סקירה מהירה
- מקבלים תמלול (SRT/TXT) ומטא-דאטה → יוצרים דיאלוג בין שני מנחים (Roee & Noa).
- ממירים את הדיאלוג לפודקאסט בעברית, ומציגים גלריה של תוצרים (אודיו, וידאו, PPTX, Story).
- שולטים בהכול מתוך ה-GUI: היסטוריית ריצות, צ'אט עם מודל AI, העלאת חומרים, ותצוגות נתונים.

## מה חדש ב-4.1
- **אפליקציה בדפדפן** (במקום ה-GUI הישן, ש-Smart App Control חוסם): `python -m src.web`, או דרך קיצור הדרך שההתקנה יוצרת. המפתחות נשמרים רק במחשב.
- **מנוע תסריט 2.0**: ניקוי ← ניתוח השיעור ← תוכנית שאפשר לערוך ← כתיבה לפי מקטעים ← בדיקת עובדות ← **עריכה של כל הפרק** (מסירה חזרות ותפרים בין מקטעים, בלי להוסיף מידע).
- **כיוון הפרק**: צלילה לעומק, למתחילים, הכנה למבחן, סיפור, דיון, **תקציר קצר**, **ביקורת**, ושדה חופשי למיקוד.
- **קולות**: ElevenLabs ‏(Text to Dialogue) או Gemini (שיחה של שני מנחים), עם השמעת דוגמה לפני בחירה. Azure נשאר כאפשרות. נרמול עוצמה לתקן פודקאסטים (‎-16 LUFS).
- **וידאו**: גלריית תמונות לכל פרויקט (שלך ו/או AI), סדר והחלפה כל X שניות, כותרות פרקים בזמן הנכון, לוגו וגופנים לבחירה.
- **עיצוב ומיתוג**: ערכת נושא בהירה/כהה, צבע מוביל, לוגו, וגופנים חינמיים מ-Google Fonts.
- **הערכת איכות**: מבקר באנגלית על 10 תרחישים (`python -m scripts.evaluate`), עם השוואה לריצה הקודמת.
- **מד עלויות** לפי מחירי Gemini ו-ElevenLabs העדכניים.

## כלים: תמלול והורדה (במסך "כלים" באפליקציה)
מה שהיה בריפו TOOLS (`hebrew_whisper` ו-`video_downloader.bat`), כחלק מהאפליקציה:
- **תמלול:** גוררים כמה קבצי וידאו ושמע שרוצים, והם מתומללים בתור. המודל נטען פעם אחת לכל הסבב ומשתחרר בסופו. עברית: ivrit.ai turbo; אנגלית או זיהוי אוטומטי: Whisper turbo הכללי. התוצאה: SRT עם זמנים וטקסט נקי. המחשב לא נכנס לשינה באמצע.
- **הורדה:** קישור אחד או רשימה, פלייליסט או קורס שלם (ממוספר לפי הסדר), איכות (הכי טובה / 1080 / 720 / שמע MP3), כתוביות עברית ואנגלית, ניסיונות חוזרים והורדה מקבילה של מקטעים. פרופילים לאתרים: Sylla (Referer ועוגיות), NachosTV (התחזות לדפדפן, אם `curl_cffi` מותקן).
- **עוגיות התחברות:** מעלים `cookies.txt` (מייצאים עם תוסף כמו "Get cookies.txt LOCALLY") ורואים עד מתי הוא בתוקף. נשמר רק במחשב (`outputs/private/cookies`), התוכן לא מוצג שוב ולא נכנס ל-git.
- **חיבור לפודקאסט:** "תמלל" על הורדה, או "לתמלל אוטומטית אחרי ההורדה", ו"צור פודקאסט" מתמלול, שממשיך ישר לתוכנית הפרק.
- לעומת TOOLS: בדיקת אישורי האבטחה (TLS) נשארת פעילה, yt-dlp מגיע מ-pip ומתעדכן, ואין קבצי exe בריפו.

## הרצה בקונטיינר (Docker)
חלופה לקובץ ההתקנה, בלי חתימה דיגיטלית: Docker Desktop חתום בעצמו, והאפליקציה רצה בתוכו על Linux.

```
docker compose up -d --build
```
ואז פותחים את `http://127.0.0.1:8765`. כרטיס NVIDIA לתמלול מהיר:
```
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d --build
```
- **מה נשמר ואיפה:** המפתחות, הפרויקטים והמודל העברי (1.6GB, יורד פעם אחת) נשמרים בתיקייה `studio-data` שליד הקבצים. בנייה מחדש של הקונטיינר לא מוחקת אותם. המפתחות לא נכנסים לקונטיינר עצמו.
- **מהאייפון:** אייפון לא מריץ קונטיינרים, אבל הוא יכול לפתוח את האפליקציה ב-Safari כשהקונטיינר רץ על מחשב או שרת. מומלץ דרך VPN (למשל WireGuard):
  1. מעתיקים את `studio.env.example` ל-`studio.env`, ממלאים את הכתובת שתפתחו (`MBS_ALLOWED_HOSTS`) וסיסמה של 12 תווים לפחות (`MBS_ACCESS_KEY`).
  2. ב-`docker-compose.yml` משנים את שורת הפורט ל-`"8765:8765"`, או לכתובת ה-VPN בלבד.
  3. בלי סיסמה האפליקציה מסרבת לעלות במצב רשת. ניסיונות ניחוש נחסמים אחרי 5 טעויות.
- לחשיפה לאינטרנט הפתוח (לא מומלץ): רק מאחורי reverse proxy עם HTTPS.

## דרישות מוקדמות
1. Python 3.9+
2. FFmpeg ב-PATH (`ffmpeg -version`)
3. Azure OpenAI (GPT-4o/4-turbo) + Azure Speech Services
4. אופציונלי: מפתח Gemini (לויזואליים/מטא-דאטה) ו-ElevenLabs (קולות פרימיום)

## התקנה והגדרת סביבה
```bash
git clone https://github.com/<org>/podcast-generator.git
cd podcast-generator
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -e .[dev]
cp .env.example .env
```
מלאו ב-`.env` את המפתחות ל-Azure OpenAI/Speech, ואופציונלית:
```env
GEMINI_API_KEY=...
IMAGEN_MODEL=imagen-4.0-generate-001
VEO_MODEL=veo-2.0-generate-001
ELEVENLABS_API_KEY=...
```

## הרצה מה-CLI
```bash
python -m scripts.generate_podcast \
  data/sample_transcript.txt \
  data/sample_metadata.json \
  --include-visuals \
  --voice-profile classic \
  --export-ppt
```
דגלים שימושיים: `--dry-run`, `--skip-cache`, `--force`, `--material`, `--url`, `--output-dir`.

## עבודה ב-GUI (M.B.S Studio)
1. הפעלה: `launch_gui.bat` (או `python -m src.gui.app`).
2. אזורים:
   - **Projects Hub**: היסטוריה, כרטיסי תוצרים, ציר זמן.
   - **Workspace**: צ'אט Gemini/Azure, העלאת קבצים/קישורים, Story חי.
   - **Control Panel**: בחירת תמלול, מצב תוצר, פרופיל קולות, הפעלת Pipeline, סטטוס ריצה.
3. כפתורי באנר: רענון/עדכונים, גיבוי/שחזור, אודות, מרכז עלויות, הגדרות תצוגה, מרכז לוגים, 🎨 הגדרות ויזואליים.
4. Voice Lab: העלאה/הקלטה, Clone with ElevenLabs, מציג יתרת תווים.

## יצירת ויזואליים עם Google AI
| מנוע | תיאור | עלות |
|------|--------|------|
| Manim | אנימציות מקומיות | חינם |
| Imagen 4 | תמונות (מפות רשת/דיאגרמות/רקעים) | $0.03-$0.06 לתמונה |
| VEO | סרטוני AI קצרים (עד 3) | ~$0.75 לשנייה |
| Hybrid | שילוב Manim + Imagen/VEO | משתנה |

הגדרות ב-`.env`:
```env
VISUAL_GENERATOR=hybrid
IMAGEN_MODEL=imagen-4.0-generate-001
VEO_MODEL=veo-2.0-generate-001
IMAGE_COUNT=5
```
אין מפתח נפרד ל-Imagen/VEO – משתמשים ב-`GEMINI_API_KEY` ובפרויקט GCP עם Vertex AI מופעל.

## מבנה הפרויקט
```
src/
├── gui/           # אפליקציית PyQt6, פאנלים, דיאלוגים, Voice Lab
├── audio/         # TTS, stitching
├── dialogue/      # יצירת דיאלוג

├── pipeline/      # runner/orchestration
├── metadata/      # מטא-דאטה, יצירת visual metadata
├── outputs/       # PPTX/Story exporters
└── utils/         # config/logging/storage/costs
```

## פתרון בעיות נפוצות
| תקלה | סיבה | פתרון |
|------|------|--------|
| 401 / 404 Azure | מפתח/endpoint/שם פריסה שגויים | בדקו את הערכים ב-`.env` (להעתיק מ-Azure Portal) |
| FFmpeg missing | FFmpeg לא מותקן/ב-PATH | `choco install ffmpeg` או הוספה ידנית ל-PATH |
| קובץ בעברית לא נקרא | אינו UTF-8 | שמירה מחדש כ-UTF-8 |
| אודיו לא מסונכרן | סגמנטים חסרים | להריץ עם `--force` |
| קריסה בהפעלה | `chat_background_path` או מפתח ישן | מחקו `config/ui_prefs.json`; החל מ־v3.1.4 מתעלם אוטומטית |
| Imagen/VEO נכשלים | מגבלת API/רשת | הפלייסהולדרים נוצרו; בדקו לוגים וסטטוס API |
