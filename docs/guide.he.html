מה המערכת עושה

M.B.S Studio הופכת הרצאה מוקלטת לפודקאסט לימודי בעברית, בסגנון NotebookLM: שני מנחים, רועי ונועה, משוחחים על החומר, מסבירים אותו דרך הדוגמאות של המרצה, ומדגישים את מה שחשוב באמת.

בניגוד לסיכום רגיל, המערכת קודם מבינה את השיעור: מה התחום, מה הרמה, אילו מושגים תלויים באילו, ואילו דוגמאות המרצה נתן. רק אז היא בונה תוכנית לפרק וכותבת אותו. כל קטע נבדק מול ההרצאה המקורית, כדי שהמנחים לא ימציאו עובדות.

אפשר להתחיל מסרטון, מקובץ שמע או מתמלול קיים (TXT, SRT או VTT).

העבודה באפליקציה

האפליקציה נפתחת בדפדפן ורצה על המחשב שלך בלבד: הכתובת היא 127.0.0.1, ואי אפשר להגיע אליה מבחוץ. אם היא כבר פתוחה, הקיצור פשוט פותח אותה שוב. כמה דקות אחרי שסוגרים את הלשונית היא נסגרת לבד, אלא אם עדיין רץ בה תהליך.

  1. פודקאסט חדש: גוררים סרטון, הקלטה או תמלול, או מדביקים קישור. אפשר לבחור סגנון, אורך ושירות קולות.
  2. תמלול וניתוח: המערכת מתמללת (בפעם הראשונה המודל העברי יורד), מנתחת את השיעור ובונה תוכנית. אפשר לסגור את הדף בזמן הזה.
  3. בדיקת התוכנית: רואים מה המערכת הבינה מהשיעור, ואפשר לשנות כותרות ומטרות, לקבוע לכל מקטע אם הוא קצר, רגיל או ארוך, להזיז, למחוק ולשנות את אורך הפרק.
  4. תסריט: לחיצה על "שמור וכתוב את התסריט". מקבלים את הדיאלוג לפי פרקים, עם מדדי איכות: אורך, כיסוי מושגים וטענות שלא נמצאו בהרצאה.
  5. פודקאסט: לחיצה על "הפק את הפודקאסט". בנגן אפשר לקפוץ בין פרקים ולראות מי מדבר עכשיו, ומשם מורידים MP3, תסריט ותמלול.
  6. וידאו (אופציונלי): תמונות, אנימציות וכתוביות. לוקח זמן, ומשתמש ב-Gemini לתמונות.
כל פרויקט נשמר בתיקייה outputs\projects. אם תהליך נכשל, למשל בגלל מפתח שגוי, מתקנים בהגדרות ולוחצים "נסה שוב": השלבים שכבר הסתיימו לא חוזרים ולא עולים כסף.

Azure OpenAI: כתיבת התסריט (חובה)

זה המודל שמנתח את השיעור וכותב את הדיאלוג. צריך שלושה פרטים: Endpoint, מפתח ושם הפריסה (Deployment).

  1. נכנסים ל-portal.azure.com ומתחברים.
  2. מחפשים למעלה Azure OpenAI, ולוחצים Create. אם כבר יש לך משאב כזה, פשוט נכנסים אליו.
  3. במשאב, נכנסים ל-Keys and Endpoint. משם מעתיקים את Endpoint (כתובת שמתחילה ב-https://) ואת KEY 1.
  4. עוברים ל-Azure AI Foundry (כפתור בדף המשאב), ואז Deployments ← Deploy model. בוחרים מודל, למשל gpt-4o או חדש יותר.
  5. שם הפריסה הוא השם שנתת לפריסה, ולא בהכרח שם המודל. מעתיקים אותו בדיוק כפי שהוא.
  6. ב-API version אפשר להשאיר 2024-02-01.
שגיאת 401 פירושה מפתח שגוי. שגיאת 404 פירושה בדרך כלל Endpoint או שם פריסה שגויים.

Azure Speech: קולות

  1. ב-portal.azure.com מחפשים Speech services ← Create. מסלול Free F0 מספיק כדי להתחיל.
  2. במשאב, נכנסים ל-Keys and Endpoint ומעתיקים את KEY 1.
  3. מעתיקים גם את Location/Region, למשל westeurope. זה מה שמזינים בשדה "אזור".

מדריך רשמי: Azure AI Speech documentation.

ElevenLabs: קולות

  1. נכנסים ל-elevenlabs.io ומתחברים.
  2. עוברים ל-API Keys בהגדרות: elevenlabs.io/app/settings/api-keys.
  3. Create API Key. מעתיקים את המפתח מיד, כי הוא מוצג פעם אחת בלבד. צריך שתהיה לו הרשאה ל-Text to Speech ול-Voices.
  4. באפליקציה: הגדרות ← מדביקים את המפתח ← טען קולות מהחשבון ← בוחרים קול לרועי וקול לנועה ← השמע דוגמה ← שמור.

המודל המומלץ הוא Eleven v4, שתומך בעברית ומייצר את שני הקולות יחד. Eleven v3 תומך גם הוא בעברית. מודלים ישנים יותר (Multilingual v2, Flash v2.5) לא תומכים בעברית. כדאי לבחור קולות שנשמעים טוב בעברית, או לשבט קול משלך.

Gemini (אופציונלי)

משמש לקולות Gemini (אם בחרת בהם), לצ'אט שבאפליקציה וליצירת תמונות (Imagen). המערכת עובדת גם בלעדיו. בקולות Gemini בוחרים קול לכל מנחה במסך ההגדרות. ברירת המחדל היא Charon לרועי ו-Aoede לנועה, ואפשר להשמיע דוגמה.

יוצרים מפתח ב-aistudio.google.com/apikey ← Create API key.

מתמלל הווידאו לעברית

המתמלל משתמש במודל של ivrit.ai: גרסה של Whisper שאומנה על עברית. הוא רץ אצלך במחשב, בלי עלות ובלי לשלוח את ההקלטה לשום מקום.

  1. פותחים את תמלול וידאו לעברית מתפריט התחל.
  2. בוחרים קובץ אחד או כמה: MP4, MKV, MOV, MP3, M4A, WAV ועוד.
  3. בסוף נוצרים לצד כל סרטון קובץ .srt (עם זמנים) וקובץ .txt (טקסט נקי).

מהירות: עם כרטיס NVIDIA התמלול מהיר בהרבה מאורך הסרטון. בלי GPU הוא רץ על המעבד ולוקח יותר זמן, לפעמים בסדר גודל של אורך הסרטון. אם ה-GPU לא זמין, המערכת עוברת למעבד לבד.

משורת הפקודה

.venv\Scripts\python -m scripts.transcribe lecture.mp4
.venv\Scripts\python -m scripts.transcribe lecture.mp4 --script     # transcribe, then build the podcast script
.venv\Scripts\python -m scripts.transcribe https://youtu.be/...      # from a link (your own lectures)

בניית תסריט

אפשר להפעיל את התהליך המלא מתוך האפליקציה. מי שרוצה שליטה מלאה יכול לבנות תסריט משורת הפקודה (מתוך תיקיית ההתקנה):

.venv\Scripts\python -m scripts.build_script lecture.mp4 --plan-only
.venv\Scripts\python -m scripts.build_script lecture.mp4

הפקודה הראשונה עוצרת אחרי תוכנית הפרק ושומרת אותה בקובץ engine\03_plan.json. אפשר לפתוח את הקובץ ולשנות כותרות, סדר, מושגים ומשקל של מקטעים. הפקודה השנייה כותבת את התסריט לפי התוכנית, כולל השינויים שעשית.

בסוף מודפס דוח: אורך משוער, כמה מהמושגים המרכזיים כוסו, האם נמצאו טענות שלא מופיעות בהרצאה, ועלות.

וידאו, לוגו וגופנים

בלשונית וידאו של כל פרויקט בונים גלריה: מעלים תמונות משלך או יוצרים תמונות AI לפי מקטעי הפרק (דורש מפתח Gemini). לחיצה על תמונה מכניסה או מוציאה אותה מהסבב, והחצים משנים את הסדר. הסליידר קובע כל כמה שניות התמונה מתחלפת. כותרת הפרק המתאים מופיעה על התמונה בזמן הנכון.

במסך עיצוב ומיתוג בוחרים ערכת נושא לאפליקציה (בהיר, כהה או לפי המערכת), צבע מוביל, לוגו (או בלי לוגו) וגופן נפרד לפרקים בעברית ובאנגלית. גופנים חינמיים מ-Google Fonts יורדים בלחיצה, ואפשר להעלות קובץ TTF/OTF משלך.

המודל המקומי

מודל קטן שרץ אצלך במחשב דרך Ollama (ברירת מחדל: gemma3:12b, כ-8GB). הוא מבצע את העבודה הזולה והחוזרת: ניקוי התמלול ובדיקת עובדות. את הכתיבה עצמה עושה Azure, כי מודלים קטנים עדיין חלשים בכתיבה יצירתית בעברית.

  • מתאים לכרטיס NVIDIA עם 8GB זיכרון ומעלה. בלי GPU הוא יעבוד, אבל לאט.
  • בלי המודל המקומי, המערכת עובדת בדיוק אותו דבר, והבדיקות פשוט רצות ב-Azure.
  • ההגדרה ב-.env: LOCAL_LLM=auto (להשתמש כשזמין), on (חובה) או off (לא להשתמש).

שינוי הגדרות

כל ההגדרות נמצאות בקובץ .env שבתיקיית ההתקנה. פותחים אותו דרך עריכת הגדרות, שומרים, ומפעילים את האפליקציה מחדש. אפשר גם להריץ את המתקין שוב: הוא יציג את הערכים הקיימים ויאפשר לשנות אותם, בלי למחוק את התוצרים.

הגדרהמשמעות
PODCAST_FORMATפורמט ברירת המחדל (ראו למעלה).
PODCAST_TARGET_MINUTESאורך פרק קבוע בדקות. 0 = אוטומטי.
DEFAULT_TTS_PROVIDERauto, azure או elevenlabs.
SCRIPT_MAX_REVISIONSכמה פעמים לנסות לתקן מקטע שנכשל בבדיקה.
DIALOGUE_ENGINEv2 (המנוע החדש) או legacy (המנוע הישן).

פתרון בעיות

מה קורהמה עושים
האפליקציה לא נפתחתפותחים שוב את הקיצור, והוא יפתח את הדפדפן לכתובת הנכונה. אם זה לא עוזר, מסתכלים ב-logs\web.log.
Windows חסם את קובץ ההתקנהאם Smart App Control פעיל, Windows חוסם תוכנות לא חתומות שהוא לא מכיר. המתקין יעבוד אחרי שהוא ייחתם בחתימה דיגיטלית. האפליקציה עצמה רצה בדפדפן, ולכן לא תלויה ברכיבים שנחסמים.
ההתקנה נעצרה באמצעבודקים חיבור לאינטרנט ומריצים תיקון התקנה. פרטים ב-logs\install.log.
401 או 404 מ-Azureמפתח, Endpoint או שם פריסה שגויים: ראו Azure OpenAI. אחרי תיקון ב-.env, מריצים בדיקת מערכת.
